City Insight | Capstone Project

A city-comparison tool built around an AI agent that queries the underlying dataset directly.

Jan–Mar 2026 · 318 automated tests · GitHub Actions CI · Vercel + Render

The interesting problem was not the data: it was the query interface. Instead of forcing users to pick metrics from a predefined list, I built an agentic tool-use loop against the Anthropic SDK, giving the model five custom tools to query the dataset directly. Independent tool calls run in parallel, and user-supplied text is guarded against prompt injection. A filter set through the chat is reflected in every view at once, and prompt caching keeps cost and latency under control as conversations grow.

React 19 · Vite · Tailwind · Leaflet · Recharts · Google OAuth · Node · Express · Firestore · Anthropic SDK · Vitest

Wildfire Command

A browser-based simulation game for managing wildfire response.

Sep 2024–Mar 2025 · Vitest

Wildfire Command is a browser-based simulation where players manage real-time wildfire response, deploying helicopters, trucks, and crews against procedurally generated terrain. I had worked in wildland fuel reduction before this, so I had a specific sense of what plausible fire spread should actually look like.

The core problem was making that behavior feel real without the simulation being prohibitively expensive. Each cell in the terrain grid maintains wind exposure, fuel load, and moisture state; spread probability is recomputed only on changed cells, not the full grid. The result is fire that reads as coherent: it runs uphill, stalls on rocky outcroppings, backs slowly into the wind, without blocking the main thread. Terrain itself is procedurally generated using Perlin noise for elevation, BSP partitioning for large-scale structure, and cellular automata to produce natural-looking fuel density variation.

Phaser 3 · JavaScript · Firebase · Webpack · Vitest

Exercise Tracker

A full-stack workout logger.

Exercise Tracker is a workout logger built to understand the full MERN stack end to end: create, view, edit, and delete exercises with name, reps, weight, unit, and date. The one decision worth calling out is weight units. Rather than normalizing on save, I store the weight and unit as entered, which keeps the data model honest but makes validation and editing unit-aware throughout.

React · Node.js · Express · MongoDB
